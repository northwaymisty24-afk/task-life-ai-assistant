# 小日子：手账视觉与每周素材库

以产品负责人上传的 `little-days-h5 (3).html`（v9）为功能和布局基线。五个栏目、日记“今天 / 这周”、整月选周、标签管理、经验收录与拖动排序均沿用该文件。本目录提供可离线打开的前端原型，不替换 `mvp/web` 的接口页面，不包含用户运行时数据，也未部署后端。

## 打开

- `little-days-h5-journal.html`：仓库版引用同目录的 `assets` 素材，请下载完整目录后打开。若需素材全部内嵌的单文件，执行 `python scripts/build.py`；仓库轻量构建执行 `python scripts/build.py --external`。
- `gallery.html`：独立素材预览，含大图与徽章缩小后的样子。
- `base-v9.html` / `handover-v9.md`：本轮收到的原始基线与交接说明。若说明和本轮明确反馈冲突，以本轮反馈为准。

## 已落实的设计选择

日记和经验本使用浅米色托斯卡纳灰泥、手工纸纹和毛边。固定的绿格与砖红格叠贴斜向右下，放在「此刻感受」和「这周有没有一点时间留给自己」的右上角。前层砖红较短，两处都用同一配色，跨盖卡片右上角，不伸到上方卡片。拼贴使用透明背景，主体的显示尺寸大于旁边的手绘图案。聊天内容区与待办采用相同的浅底色。原画三个人物与淡沙地纹理在「聊天」标题旁展开，线描与底色正片叠底，边缘柔化；顶部暖黄渐变至米白。标题下的说明移进聊天输入框，提示为「记待办、拆步骤，或者聊聊卡在了哪里…」。助手气泡米白、用户气泡灰绿。手绘小图固定为 55×55px。标题胶带每周换一组，今天和这周共享，新增浅粉蓝灰小花与烟灰雾纹，水泥灰仍在原组。周回顾保留波浪线、纸质图表和加宽荧光笔鼓励语，鼓励语旁的人物或猫狗场景按周更换，「此刻的感受」标题右侧同样使用每周活动插画。两处都使用真实透明底文件；右上角格纹胶带保持原锚点。徽章位于日历周行旁。安排明天收起时也可以进入聊天并带上「明天我想」。

待办和日记「安排明天」共用的排序手柄改为单色简笔狗爪；保留 44px 点击范围、拖拽及键盘上下方向键调整。原始 `base-v9.html` 不改，构建时统一替换两处手柄和说明文字。

## 素材库

- **43 张拼贴**包含 4 张原创、`feature/photos` 的 36 张及本轮新增的三只乌鸦、狸花猫、奶牛猫三张透明拼贴。10 张摄影与拼贴同页的源图仅导入拼贴裁片，其余 26 张保留完整拼贴构图。36 张均清除外围白纸底，保留主体内部的白色细节。原文件路径、SHA 与裁切范围记录于 `reference-sources.json`。
- **88 张手绘**包含原有 34 张、新增 52 个活动场景，以及下班打卡、洗水果 2 张日常小图。活动池共有 64 张透明人物或猫狗素材，动物也按用户确认归入活动场景。新增人物包括喷补水喷雾、草地晒背、沙滩椅喝椰汁、跳舞、烘焙、堆沙堡。每个活动场景均为独立透明 WebP，不使用带纸底的截图方块。
- **53 枚参考图**按原图顺序保存在 `assets/reference` 的透明图集与索引中，可逐图查看。
- **18 卷标题胶带**分为 9 对，由 `tapes.json` 定义。固定的两条格纹角贴独立于每周标题配色。另有两枚纸质周徽章，以及 **30 枚习惯徽章**。习惯徽章由 AI 预先生成，运行时按习惯名称匹配；常见习惯使用对应图案，未知习惯采用稳定的默认徽章。原型不会临时调用图片生成 API。

## 每周自动更换

栏目可直接左右轻滑切换，没有额外底部翻页窗口或提示栏；手机端轻扫阈值降低，使用合成层平移与短时缓动，并可点击页面左右各 18% 的空白区域翻页。触摸输入控件、任务排序和经验卡片时优先保留原操作。未提交输入在栏目切换后保留。

本功能已按用户确认采用“网页每周自动换现有素材”，没有建立外部定时生成或自动提交任务。

1. 以浏览器本地日期、周一为每周起点。标题胶带按周循环，同一周在两页用同一对。
2. 选一张拼贴、一个配套小图案，以及「留给自己」「此刻的感受」各自的一张活动插画。按日历周确定、缓存；不根据用户未明确表达的信息推测心情或健康状态。
3. 一周首次展示后，四处素材 ID 缓存在本机 `state.journalDecorWeeks[周一日期]`。同一周刷新、跨页、继续写日记都不重新抽；新一周优先选不同的素材。
4. 查看历史某周时读取该周自己的组合。记录只有浏览器内一份；换浏览器或清除本地缓存后，会根据当时记录重新选择，不承诺跨设备保持相同组合。
5. 页面一直开着跨周时，每分钟及重新进入标签页时只更新装饰，不重渲染输入框。这个计时器不是后台消息发送或云端任务。

周回顾的鼓励是本地按记录选择的简短文案，不冒充模型个性化分析。有生活片段时肯定用户留下的具体生活和感受；记录少时邀请晒太阳、听歌等小事，不把“没有记录”说成“没照顾自己”。

## 新增或修改素材

1. 把新文件放入 `assets/collages` 或 `assets/doodles`。
2. 在 `manifest.json` 的 `assets` 中新增一项：

```json
{
  "id": "unique-and-stable-id",
  "label": "素材名称",
  "kind": "collage",
  "contexts": ["outdoors", "neutral"],
  "path": "assets/collages/new-art.webp",
  "enabled": true,
  "origin": "generated",
  "version": 1
}
```

`contexts` 支持 `learning`、`rest`、`outdoors`、`neutral`；选择某类时少于两个可选项，会退回全库，保证有轮换空间。ID 一经使用应保持稳定；替换内容可保留 ID 并增加 version。禁用或删除已缓存素材后，该周会重新选择可用组合。

3. 在本目录执行 `python scripts/build.py`。会生成应用单文件、素材预览及 `dist`。构建不会覆盖已有的 manifest，因此添加素材无需修改 JS 或构建脚本。

默认构建内嵌字体和素材；`--external` 构建引用独立素材文件，原型没有读取 GitHub 或调用模型的运行时请求。线上多人版要把周组合改为服务端按会话用户保存，避免把用户身份写进 URL；这次仅新增前端表现，不代表后端联调完成。

## 代码与验证

- `journal.css`：有范围限制的视觉层，日记与经验本采用手工纸卡，聊天页采用原画沙地纹理。
- `journal-assets.js`：独立透明插画、习惯徽章匹配与经验本顶部本子图案。
- `section-swipe.js`：栏目横向滑动与未提交输入保留。
- `enhancements.css`：55px 图案、大号今天/这周按钮与原角贴位置。
- `journal.js`：周组合、鼓励、徽章，以及原版 render 后的装饰。
- `tapes.json`：标题胶带色、纹样、轮换顺序与起始周。
- `scripts/create-vector-assets.py`：可编辑 SVG 的生成源。
- `scripts/build.py`：无第三方依赖的 Python 构建脚本。

构建产物可离线运行。后端身份与数据接口沿用原交接的待办状态。
