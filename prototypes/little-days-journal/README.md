# 小日子：手账视觉与每周素材库

以产品负责人上传的 `little-days-h5 (3).html`（v9）为功能和布局基线。五个栏目、日记“今天 / 这周”、整月选周、标签管理、经验收录与拖动排序均沿用该文件。本目录提供可离线打开的前端原型，不替换 `mvp/web` 的接口页面，不包含用户运行时数据，也未部署后端。

## 打开

- `little-days-h5-journal.html`：下载后直接用浏览器打开，字体、主插图和新增素材均内嵌。
- `gallery.html`：独立素材预览，含大图与徽章缩小后的样子。
- `base-v9.html` / `handover-v9.md`：本轮收到的原始基线与交接说明。若说明和本轮明确反馈冲突，以本轮反馈为准。

## 已落实的设计选择

日记和经验本使用浅米色托斯卡纳灰泥，卡片沿边做了手工纸纤维、毛边和贴纸阴影。日记“今天”的回顾卡内附一张拼贴、一个手绘图案和角落胶带。“安排明天”的黄色胶带按钮在折叠时也看得见，打开聊天后会预填「明天我想」。桌面侧栏与手机页头统一使用同一个淡黄色左耳小狗标志。

日记“这周”保留整月逐行选周与疏朗波浪线。三段标题按顺序使用鹅黄点纹、淡紫格纹与暖橙斜纹胶带。完成事项的图表使用纸质柱，鼓励文字以手绘荧光笔笔触承托。周回顾的拼贴贴在卡片内。徽章采用 B 纸质圆章，皇冠只留中间一颗红点，玫瑰花头收窄。徽章显示在日历对应周行旁。

## 素材库

- 4 张胶带拼贴，包括茶杯与书、新芽与笔记、窗边阳光、树下长椅。
- 10 个原创手绘图案，包括 6 个重画的彩铅小人和 4 个简笔小物。
- 2 个彩色徽章，以及托斯卡纳灰泥、手工纸纹与三款标题胶带。
- 53 个用户提供的参考图案，按原图顺序保存在 `assets/reference` 的透明图集与索引中，可在素材库预览逐图查看。这一组作为参考画册，日记继续轮换原创素材。

拼贴、彩铅小人与灰泥纹理使用优化后的 WebP。其余参考见 `reference-sources.json` 与仓库的 [feature/photos](https://github.com/northwaymisty24-afk/task-life-ai-assistant/tree/feature/photos)。

## 每周自动更换

本功能已按用户确认采用“网页每周自动换现有素材”，没有建立外部定时生成或自动提交任务。

1. 以浏览器本地日期、周一为每周起点。
2. 选一张拼贴和一个小图案。只参考当周用户明确记录的活动关键词与习惯日志，例如阅读、散步、喝茶；不猜测情绪、能力或健康状态。无记录时用中性组合。被排除回顾或撤销的记录不用于选择。
3. 一周首次展示后，两个素材 ID 缓存在本机 `state.journalDecorWeeks[周一日期]`。同一周刷新、跨页、继续写日记都不重新抽；新一周优先选不同的素材。
4. 查看历史某周时读取该周自己的组合。记录只有浏览器内一份；换浏览器或清除本地缓存后，会根据当时记录重新选择，不承诺跨设备保持相同组合。
5. 页面一直开着跨周时，每分钟及重新进入标签页时只更新装饰，不重渲染输入框。这个计时器不是后台消息发送或云端任务。

周回顾的鼓励是本地按记录选择的简短文案，不冒充模型个性化分析。有生活片段时肯定用户留下的具体生活和感受；记录少时邀请晒太阳、听歌等小事，不把“没有记录”说成“没照顾自己”。

## 新增或修改素材

1. 把新文件放入 `assets/collages` 或 `assets/doodles`。
2. 在 `manifest.json` 的 `assets` 中新增一项：

```json
{
  "id": "unique-and-stable-id",
  "label": "素材名称",
  "kind": "collage",
  "contexts": ["outdoors", "neutral"],
  "path": "assets/collages/new-art.webp",
  "enabled": true,
  "origin": "generated",
  "version": 1
}
```

`contexts` 支持 `learning`、`rest`、`outdoors`、`neutral`；选择某类时少于两个可选项，会退回全库，保证有轮换空间。ID 一经使用应保持稳定；替换内容可保留 ID 并增加 version。禁用或删除已缓存素材后，该周会重新选择可用组合。

3. 在本目录执行 `python scripts/build.py`。会生成应用单文件、素材预览及 `dist`。构建不会覆盖已有的 manifest，因此添加素材无需修改 JS 或构建脚本。

字体和素材都在构建时内嵌，原型没有读取 GitHub 或调用模型的运行时请求。线上多人版要把周组合改为服务端按会话用户保存，避免把用户身份写进 URL；这次仅新增前端表现，不代表后端联调完成。

## 代码与验证

- `journal.css`：有范围限制的视觉层，仅日记与经验本使用背景。
- `journal.js`：周组合、鼓励、徽章，以及原版 render 后的装饰。
- `scripts/create-vector-assets.py`：可编辑 SVG 的生成源。
- `scripts/build.py`：无第三方依赖的 Python 构建脚本。

构建产物可离线运行。后端身份与数据接口沿用原交接的待办状态。
