## 2. 我目前完成到哪里

**已做成可操作的离线前端原型：**

- 以 v9 HTML 和交接文档为功能基线，保留五栏、日记今天／这周、日期与选周、待办排序、习惯、聊天、经验本的本地交互。
- 经验本在原型中已有收录、可编辑标题与正文、原话切换、每条两个标签／每人十个在用标签、搜索、标签管理、移出及“让助手参考”开关。
- 日记与经验本的纸张和手账视觉、拼贴图、手绘图、胶带及每周轮换规则已放在 [视觉原型目录](../prototypes/little-days-journal/README.md) 的功能分支；[视觉 PR](https://github.com/northwaymisty24-afk/task-life-ai-assistant/pull/1) 尚待评审。
- 原型生成的单文件可离线打开，数据暂存浏览器 localStorage；周素材选择也只在本机缓存。原仓库的基础 H5／两表服务是另一套已有实现，两者尚未集成。

**尚未完成，不能说成已交付：**

- 小日子原型未接 /api/v1/turns、/api/v1/tasks、/api/v1/corrections、来源查询，也未接真实用户身份；演示数据不跨设备。
- 日记片段、经验条目、授权画像及历史周回顾尚无冻结的后端契约、可用接口和持久化迁移；前端的经验整理 tidy 只是本地占位。
- 公众号真实测试号回调、文字／语音、身份深链接、异步下行能力和多用户隔离尚缺真机验收；本地 mock 不等于微信联调。
- SPEC v1.0 的待确认区、部分完成／数量打卡等前端缺口仍在；部署、CI、验收用例必须以各负责人最新结果核对。
