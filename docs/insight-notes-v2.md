# 下一版提案：把日记里的经验收进「经验本」

状态：讨论稿。首版范围、数据库和接口以已评审的 SPEC 与共享契约为准。本提案依赖首版先具备可回溯的独立日记片段能力，独立日记的数据方案仍以团队评审结果为准。

## 1. 两种记录，各自解决什么

| 记录 | 我什么时候会找它 | 举例 |
| --- | --- | --- |
| 日记感受 | 想回看某天发生的事、当时的感受或想到的话 | 「跟朋友聊天以后没那么焦虑了」 |
| 经验总结 | 下次遇到类似情形，想找回自己试过的方法、观察或感悟 | 「请人帮忙时，把我需要的结果和最后期限一起说清楚」 |

辨别线索是「以后还想翻出来用或读吗」。篇幅只影响是否适合提示，一句短话也可以是经验，长段倾诉也可以全是日记。同一段同时包含感受和经验时，保留原话和当天回顾，只把用户选中的片段收进经验本。与他人有关的偏好只作为用户明确保存的私人笔记，可由本人更正。后续如需标签，可考虑「做事方法」「学习」「人情往来」「人物偏好」「生活体会」。

## 2. 页面与保存方式

1. **聊天**用来记事项、拆步骤、说感受。合格的感想按 PRD 默认进入日记，聊天里仍能回看原消息。消息右下角保留轻量操作「在日记里看」「收为经验」。前者直达当天回顾的来源片段。补漏用「留进日记」，成功后就地变为「已留进日记 · 查看」。长段消息也用同一处入口。右侧小便签用「今天的经验总结」，只展示最近一条已确认的经验，手机上放在聊天标题附近的可收起小便签。
2. **晚间日记**按「今日回顾 → 此刻的感受 → 安排明天」组织。今日回顾收起时展示一段摘要，展开后按时间回看事实和原话。较长的思考可在同一卷轴内以引文呈现，已收录的句段旁标「已收为经验」。用户写完今晚的感受后，也能选一段收为经验，保留日记原文。
3. **经验本**先做成晚间日记标题旁一个轻入口。打开后按新旧浏览已有条目，每条显示标题或首句、保存日期与「查看原话」。内容积累后再考虑主题筛选与搜索。
4. 聊天快捷开头「经验总结」是显式意图，发送后回显待收录内容。用户可确认范围、改标题或取消。手动入口先上线。模型联调后可为少量明确、可复用的句段给一张可忽略的建议卡，只有用户确认才新增经验记录。

示例：用户说「名单发出去之后松了口气。以后请同学帮忙时，我想把要交付的东西和截止时间放在同一条消息里。」当天日记保留原话；若用户确认，经验本只收第二句。提到感受、经验或人物偏好本身不会创建待办、习惯、提醒或画像。

## 3. 最小数据方案

首版的原话与日记片段数据仍是事实来源。下一版可新增一张轻量 `insights` 表，作为与日记分开的私有资料区。优先用引用表示选中的原话范围，避免复制聊天和日记原文。

| 字段 | 用途 |
| --- | --- |
| `id`, `user_id` | 条目和所属用户 |
| `source_event_id`, `source_reflection_id`（可空） | 追溯聊天或晚间日记。来源必须属于同一用户 |
| `quote_start`, `quote_end` | 标记同一原文中的连续范围。接口约定字符位置语义，服务端校验范围 |
| `title`（可空） | 用户可编辑的简短标题 |
| `created_at`, `revoked_at`（可空） | 确认保存时间、撤出经验本时间 |

建议卡在确认前只作为候选展示。确认请求重试应幂等，同一来源同一范围的有效条目只留一条。撤出经验本保留原日记。原文明确删除时，按 Q-13 的删除口径同步处理引用、派生文本与缓存。原话被排除回顾时，经验条目也不得成为周回顾或画像的间接入口。首版的排除按钮排期和后端执行口径分别以团队评审为准。

## 4. 实现顺序

| 顺序 | 内容 | 建议主责 |
| --- | --- | --- |
| 1 | 确定日记片段、身份、来源关联和删除语义；评审经验条目的共享契约 | A/B/C |
| 2 | 消息小字收录、日记内轻入口、按日期读取、撤出经验本 | A 交互，C 数据，B 协调跨入口回执 |
| 3 | 让晚间日记的段落也可收录；再试少量模型建议 | A 交互，B 提示策略，C 校验与读写 |

页面小入口与样式改动较小。真正跨端可用需要共享契约、按用户查询、确认去重、撤出与来源删除联动，属于下一版的独立交付。模型自动提炼可以晚于手动入口。

## 5. 验收样例

| 输入或操作 | 期望结果 |
| --- | --- |
| 「今天下楼时风很舒服。」 | 日记有原话；经验本、任务和画像均无新增 |
| 一次聊天里同时有感受和实用方法 | 日记正常留存；确认范围后，只有选中的方法进入经验本 |
| 短句经验及长段倾诉各发一条 | 短句可经确认收录；长段随笔可完整留在日记 |
| 忽略模型建议、或重复点击确认 | 忽略时经验本零写入；重复确认仍只有一条有效记录 |
| 指定「这句别记」、排除回顾，或只撤出经验 | 三种动作分别按现有删除、排除和经验撤出语义执行 |
| 用另一个账号打开来源或经验条目 | 服务端校验所属用户，查询与修改均无法越权 |
